# Фронтенд

- Чистые HTML/CSS/JS, без фреймворков, сборки и CDN.
  При создании или переработке интерфейса загружай скил `frontend-design`.
- JS: ES-модули не нужны, `const`/`let`, `fetch` к API бэкенда.
- Пользовательский ввод в DOM — через `textContent`, не `innerHTML`.
- Разметка семантическая (`header`, `main`, `form`, `label`), адаптивная вёрстка (mobile-first).
- Стили в `style.css`.
