# Python-бэкенд

- Только стандартная библиотека (`http.server`, `sqlite3`, `json`, `unittest`, `logging`).
- Аннотации типов на всех публичных функциях — их проверяет pyright через хук после каждой правки.
  Идиомы типизации и запуск pyright — в скиле `python-best-practices`.
- Исправляй ошибки, которые хук вернул в `additionalContext`, до перехода к следующему шагу.
- API отдаёт и принимает JSON, коды ответов осмысленные.
- Ошибки не глотать молча: логировать и возвращать JSON `{"error": "..."}`.
- Новая логика — с тестом в `tests/`.
