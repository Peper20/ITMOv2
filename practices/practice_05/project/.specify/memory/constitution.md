# «Сроки» Constitution

## Core Principles

### I. Минимум зависимостей
Бэкенд — только стандартная библиотека Python 3.12+ и SQLite. Фронтенд — Svelte + Vite,
без CDN и внешних запросов в рантайме. Новая зависимость требует обоснования в plan.md.

### II. Контракт API — JSON, ошибки явные
API под `/api` принимает и отдаёт JSON. Ошибка валидации — HTTP 400 и
`{"error": "<текст для человека>", "field": "<поле>"}`. Ошибки не глотаются молча.
Изменение контракта сначала фиксируется в `contracts/`, затем в коде.

### III. Тесты на новую логику (NON-NEGOTIABLE)
Новая логика бэкенда — с тестом в `tests/` (`unittest`, временная БД). Чистые функции
фронтенда — с тестом vitest. Сквозной сценарий фичи проверяется в настоящем браузере.

### IV. Данные и миграции
SQL только параметризованный. Схема меняется явной миграцией через `PRAGMA user_version`;
существующие данные после миграции остаются валидными.

### V. Простота
Узкие границы изменения, без задела «на будущее». Существующее поведение сохраняется,
если спецификация явно не говорит обратное.

## Ограничения

Однопользовательское локальное приложение без авторизации. Время локальное, без часовых
поясов: `YYYY-MM-DDTHH:MM`.

## Процесс

Спецификации UI и логики согласуются через общий контракт до генерации кода. Решения по
расхождениям принимает человек. Проверки перед приёмкой: `python3 -m unittest discover tests`,
`npm test`, `npm run check`, `npm run build` в `frontend/`.

## Governance

Constitution главнее остальных практик проекта. Изменения — правкой этого файла с новой версией.
