# Proposal

## Why

Фильтры календаря (категория и поиск) сбрасываются только вручную, по одному: выбрать «Все
категории» и стереть строку поиска. Из-за забытого фильтра легко решить, что дедлайнов нет.
Нужна одна кнопка, которая возвращает полный список.

## What Changes

- В панели фильтров появляется кнопка «Сбросить», видимая только при активном фильтре.
- Нажатие очищает категорию и поиск, отменяет отложенный поиск и один раз перезагружает
  календарь и боковую панель; фокус переходит в поле поиска.
- Бэкенд, API и хранение фильтров не меняются.

## Capabilities

### New Capabilities
- `deadline-filters`: фильтрация календаря по категории и тексту и сброс фильтров.
