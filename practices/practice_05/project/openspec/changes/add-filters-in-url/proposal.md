# Proposal

## Why

Фильтры теряются при перезагрузке страницы, и ссылкой на отфильтрованный календарь нельзя
поделиться: в хэше адреса сейчас только вид и дата.

## What Changes

- Категория и поиск записываются в хэш (`#view=week&date=…&cat=3&q=лаба`) и читаются из него
  при открытии страницы.
- Сброс фильтров (см. `deadline-filters`) убирает `cat` и `q` из хэша, вид и дата остаются.
- Бэкенд и API не меняются.

## Capabilities

### New Capabilities

### Modified Capabilities
- `deadline-filters`: фильтры сохраняются в адресе; сброс теперь меняет хэш (только параметры фильтров).

## Impact

- `frontend/src/lib/route.ts` и `route.test.ts` — формат хэша.
- `frontend/src/lib/app.svelte.ts` — чтение и запись фильтров в хэш.
