# Spec Delta

## ADDED Requirements

### Requirement: Фильтры сохраняются в адресе
Активные фильтры SHALL записываться в хэш адреса параметрами `cat` (id или `none`) и `q`
(обрезанный текст) рядом с `view` и `date`. При открытии страницы фильтры MUST
восстанавливаться из хэша. Пустые фильтры MUST NOT попадать в хэш.

#### Scenario: Открытие ссылки с фильтрами
- **WHEN** пользователь открывает `#view=week&date=2026-10-10&cat=3&q=лаба`
- **THEN** выбрана категория 3, в поиске «лаба», календарь загружен с этими фильтрами

#### Scenario: Неизвестная категория в адресе
- **WHEN** в хэше `cat=999`, а такой категории нет
- **THEN** фильтр категории сбрасывается на «Все категории», как при удалении выбранной категории

#### Scenario: Без фильтров
- **WHEN** фильтры пустые
- **THEN** хэш имеет прежний вид `#view=…&date=…`

## MODIFIED Requirements

### Requirement: Сброс не меняет остальное состояние
Сброс MUST NOT менять вид (месяц/неделя), показываемый период, выбранный день, состояние
боковой панели и тему.

#### Scenario: Вид и период сохраняются
- **WHEN** открыт вид «Неделя» на другой неделе и пользователь нажимает «Сбросить»
- **THEN** вид и неделя остаются прежними; из хэша адреса пропадают только `cat` и `q`
