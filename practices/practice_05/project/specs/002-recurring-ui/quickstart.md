# Quickstart: проверка UI

```bash
cd frontend && npm test && npm run check && npm run build && cd ..
PORT=8001 DB_PATH=/tmp/sroki-rec.db python3 backend/server.py
```

Сквозной сценарий в браузере (`http://127.0.0.1:8001`):

1. «Новый дедлайн» → «Повтор: Каждую неделю» → «Добавить»: у дедлайна значок повтора.
2. Флажок «Готово» → сообщение «Следующий — <дата>», «Показать» переходит к дню, там новый дедлайн.
3. Снять флажок → «Следующий дедлайн на <дата> остался»; снова отметить → без сообщения, дубля нет.
4. Ошибка/граница: срок 31.01 «Каждый месяц» → следующий 28.02; связь с сервером оборвана → флажок откатился, полоса ошибки.
